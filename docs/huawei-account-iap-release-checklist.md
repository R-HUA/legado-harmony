# 华为账号、点数与 IAP 上线清单

当前版本暂时关闭账号商业服务入口（`COMMERCE_ENABLED = false`），移除账号页路由，禁止非同步业务请求；仅保留既有同步接口及已启用同步所需的会话续期。内置主题及其部件全部免费，服务器在线朗读暂停。以下清单保留供未来重新接入时核对，不代表当前功能已开放。恢复入口前需要重新评估产品范围、登录配置与发布验证。

本清单对应应用内的华为账号登录、点数充值和主题权益功能。代码完成不等于可以直接发布；以下带“必须”的项目应在正式上架前完成。

## 控制台与服务端

- 必须在 AppGallery Connect 开启 Account Kit，并将真实 OAuth Client ID 填入 `entry/src/main/module.json5`。
- 必须开通华为商户服务和 IAP Kit，将四个点数包配置成“消耗型”数字商品。
- 必须部署 `server` 到 HTTPS 服务，并将地址填入 `AccountCommerceConfig.API_BASE_URL`。
- Client Secret、IAP `.p8` 私钥、Issuer ID、数据库凭据必须只放在服务端密钥管理中。
- 必须使用华为当前站点文档给出的 IAP Server API 根地址和 Huawei CBG Root CA G2 证书。
- 必须配置数据库备份、账本审计、告警、限流和日志脱敏。

## 用户协议与隐私

- 必须提供可访问的用户协议、隐私政策和点数服务规则，并在登录/购买前提供明确入口。
- 隐私政策至少说明：华为 OpenID/UnionID、昵称和头像的处理目的、保存期限、服务器地域、共享对象、用户权利和联系渠道。
- 仅申请业务必需的账号 scope；当前业务不需要手机号、通讯录或其他额外身份信息。
- 应提供账号数据查询、更正、删除/注销和撤回授权渠道，并明确注销后剩余点数及未到期主题如何处理。
- 如服务涉及未成年人，必须根据目标市场增加年龄分级、监护人同意和未成年人消费保护。

## 付费与售后

- 购买页和收银台前必须清楚展示商品名称、价格、到账点数和兑换比例；实际价格以 IAP 查询结果为准。
- 明确点数仅用于本应用数字内容，不得转让或提现；不要把点数宣传为投资、储值理财或通用支付工具。
- 必须公布退款、撤销、误购、未到账和客服处理规则。退款后的点数冲正应基于 IAP 关键事件通知与订单查询实现。
- 主题应明确标注“60 点、365 天、非自动续期”，到期后不得暗中续费或自动扣点。
- 必须保存订单号、账本、权益变更和用户确认记录，以便对账与争议处理。

## 测试

- 使用 IAP 沙盒测试支付成功、取消支付、重复点击、客户端断网、服务端超时和确认订单失败后的恢复。
- 验证同一华为账号在两台设备登录后余额和主题到期时间一致。
- 并发验证同一账号首登只赠送一次 300 点、同一主题请求只扣一次 60 点、同一 IAP 订单只入账一次。
- 验证服务端不接受伪造商品 ID、篡改 JWS、错误 App ID/包名、已退款或撤销订单。
- 上架材料中选择“购买虚拟币”等实际应用内资费类型，并随版本提交消耗型商品信息。

正式发布前应由熟悉目标市场的律师或合规人员审核协议、隐私政策、退款规则和税务处理。本文件是工程上线清单，不构成法律意见。
